# Welcome to NoteTaker

This is your personal, lightweight Markdown notes app. Everything you write is
saved as a plain `.md` file on your computer — portable and future-proof.

## What you can do

- **Format with Markdown** — headings, **bold**, *italic*, lists, tables, and code:

  ```python
  def hello():
      print("Notes as code blocks work too!")
  ```

- **Link notes together** with double brackets: type `[[` and pick a note.
  Try creating a note and linking it here, e.g. `[[My First Topic]]`.

- **Tag notes** with `#hashtags` to group them by topic. This note is tagged
  #reference and #getting-started — click a tag chip on the left to filter.

- **Search** everything from the box on the left.

- **Backlinks & Graph** (right panel) show how your notes connect. Any note that
  links to this one appears under *Backlinks*, and *Graph* draws the whole web.

## Ideas for how to use it

| Use case            | Example note                          |
|---------------------|---------------------------------------|
| Learning something  | "React Hooks", "Bayes Theorem"        |
| Exam prep           | "Networking Exam — Subnetting" #exam  |
| Process reference   | "How to deploy to AWS" #process       |

> Tip: press **Cmd/Ctrl + N** any time to create a new note.

Happy note-taking! 🎉
